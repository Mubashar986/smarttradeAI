# Architecture Decision Template

Use this template when a design choice affects more than one role, changes an interface, or creates a durable constraint.

```text

Requirement:

Options considered:
1.
2.
3.

Selected option:

Rationale:

Rejected:

Affected interfaces:

Affected roles:

Verification:

Risks:

Rollback or migration:

Handoff:
```

## Decision Quality Checklist

- Does the decision name the user or system behavior it enables?
- Does it identify the interface boundary?
- Does it preserve MVP scope?
- Does it state what evidence will prove the decision worked?
- Does it tell the next specialist exactly where to start?
